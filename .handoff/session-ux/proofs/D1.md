# D1 — the specification describes the shipped session behavior

## Automated evidence

The specification and requirements addendum name the persisted backend,
reflink-only adapter seed skip, nonfatal session creation, dual-TTY attachment,
per-tree `open --all` failure data, and deferred status line. The runtime tests
linked by A1 and B1–B9 exercise those rules.
