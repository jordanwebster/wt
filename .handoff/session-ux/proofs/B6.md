# B6 — open all covers live trees, resumes, and contains failures

## Automated evidence

`agents_start_only_for_new_sessions_and_open_all_resumes_recorded_agents`
asserts all three live trees are reported, the recorded tree uses `resume`, and
an additional non-JSON `open --all` route leaves the real private server with
zero attached clients. `open_all_reports_each_tree_and_continues_after_a_failure`
places the middle tree in `replaced`, then asserts the canonical and later tree
are created, the failure is retained in data, `ok` is false, and exit 5 is
chosen only after all three outcomes exist.

## Gap

The contained failure is `TREE_REPLACED`; a per-tree `LOCK_TIMEOUT` is not
injected. Both share the same containment loop and worst-exit selection, but
that second failure class remains unobserved end to end.
