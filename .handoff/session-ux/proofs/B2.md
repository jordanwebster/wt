# B2 — the live session carries the tree environment

## Automated evidence

`new_attaches_and_the_live_pane_has_the_tree_environment` sends `command -v
tree-tool` plus prints of `$WT_ROOT` and `$WT_PORT_HTTP` into the live pane,
polls `capture-pane -p` for `__TREE_ENV__`, and asserts the linked tree's exact
binary, root, and port. The retained golden capture is
`tests/snapshots/session_flow__session_tree_environment.snap`.

## Demonstration

Captured from the private tmux pane:

```text
<ROOT>/wt-home/trees/repo/work/bin/tree-tool
ROOT=<ROOT>/wt-home/trees/repo/work PORT=20016
__TREE_ENV__
sh-3.2$
```

Replay: `cargo test --test session_flow new_attaches_and_the_live_pane_has_the_tree_environment -- --exact --nocapture`

## Gap

Gap: this proves one declared binary directory and one named port end to end;
the existing environment contract suite covers multiple bins and aliases.
