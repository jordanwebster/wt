## Automated evidence

`new_attaches_and_the_live_pane_has_the_tree_environment` opens the canonical
tree with neither `session.agent` nor `--agent`, waits for a client on a real
private tmux server, sends a command whose output marker is not present in the
typed command, and captures that output from the live shell. It also asserts
the former “no agent was selected” failure is absent.
