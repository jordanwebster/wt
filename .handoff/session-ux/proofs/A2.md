# A2 — open without an agent

## Automated evidence

`new_attaches_and_the_live_pane_has_the_tree_environment` opens the canonical
tree after its `new` session exits, with no `session.agent` and no `--agent`.
It observes a private tmux client attached to a live interactive shell, drives
that shell with `send-keys`, and asserts that the old “no agent was selected”
failure is absent.

## Demonstration

Captured from the test's second private-tmux session:

```text
Session created for repo
sh-3.2$ printf '__OPENED_SHELL__\n'
__OPENED_SHELL__
sh-3.2$
```

Replay: `cargo test --test session_flow new_attaches_and_the_live_pane_has_the_tree_environment -- --exact --nocapture`

## Gap

Gap: the test fixes the shell to `/bin/sh` for deterministic CI; selection
from a user's `$SHELL` is covered by the shared `wt shell` selector, not by a
second real-shell matrix here.
