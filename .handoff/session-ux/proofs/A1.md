# A1 — adapter seeds reach a new tree

## Automated evidence

`cargo_adapter_seeds_new_trees_and_tracks_adapter_sync_inputs` probes reflink
support on the fixture filesystem, then asserts the Cargo adapter's `target`
entry is materialized only when every file can be cloned. On a non-cloning
filesystem it instead requires `SEED_SKIPPED_NO_REFLINK`, an absent
destination, no materialized record, and no `SEED_COPIED_NOT_CLONED`. The same
test observes both Cargo sync inputs and later drift.

`required_reflink_reports_unavailable_and_removes_partial_destination` drives
the clone-only filesystem decision directly with the reflink-unavailable
failpoint and asserts `Unavailable` plus complete cleanup. Repository-declared
seed fallback remains covered by `unsupported_reflink_falls_back_per_file`.

## Demonstration

Retained capture: `captures/A1.txt`. Its observed block is quoted verbatim:

```text
--- A1 ---
reflink supported: true
adapter seed present: true
SEED_SKIPPED_NO_REFLINK: false
sync inputs: Cargo.lock, Cargo.toml
```

Regenerate it exactly with:

```sh
env WT_PROOF_CAPTURE=A1 cargo test --quiet --test contracts cargo_adapter_seeds_new_trees_and_tracks_adapter_sync_inputs -- --exact --nocapture > .handoff/session-ux/captures/A1.txt 2>&1
```

## Gap

This retained run was on a reflink-capable filesystem, so it demonstrates the
clone outcome. The non-cloning outcome is forced at the filesystem decision
boundary rather than by mounting another filesystem in the integration test;
the contract test conditionally asserts the orchestration notice when its real
probe reports no support. Neither test inspects physical extent sharing with a
filesystem-specific diagnostic.
