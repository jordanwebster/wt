# B7 — backend none means no tmux

## Automated evidence

`backend_none_never_invokes_tmux_for_truth_or_teardown` puts a recording shim
first on PATH, runs `list`, `remove`, `prune`, `open`, and `close`, and checks
the invocation file remains absent. It also requires the two session verbs to
return `SESSION_DISABLED` with the setting and enabling value.

## Demonstration

Retained capture: `captures/B7.txt`. Verbatim observed block:

```text
--- B7 ---
list/remove/prune/open/close tmux invocations: 0
```

Regenerate it exactly with:

```sh
env WT_PROOF_CAPTURE=B7 cargo test --quiet --test session_flow backend_none_never_invokes_tmux_for_truth_or_teardown -- --exact --nocapture > .handoff/session-ux/captures/B7.txt 2>&1
```

## Gap

The absence oracle is a missing log file and the test has no direct positive
control that invokes the replacement shim after the negative assertions; it
therefore also passes if that shim were unreachable. The refusal output is a
separate positive observation of the selected backend behavior.
