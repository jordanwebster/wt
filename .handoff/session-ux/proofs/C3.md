# C3 — terminal and redirected `new` output agree

## Automated evidence

`redirected_output_matches_the_terminal_text` runs `new` against equivalent
isolated homes once through a pseudoterminal and once with captured non-TTY
stdout. After removing the terminal driver's CR from CRLF and normalising each
temporary root, it asserts byte-for-byte equality, including the single `next`
row. The same test retains comparisons for status, tasks, config, and locks.

## Demonstration

Retained capture: `captures/C3.txt`. This is the compared `new` output,
verbatim:

```text
--- C3 ---
Created repo/work
  path    <ROOT>/wt-home/trees/repo/work
  branch  work
  sync    skipped
  next    run `wt build repo/work` to create <ROOT>/wt-home/trees/repo/work/bin
```

Regenerate it exactly with:

```sh
env WT_PROOF_CAPTURE=C3 cargo test --quiet --test human_transcripts redirected_output_matches_the_terminal_text -- --exact --nocapture > .handoff/session-ux/captures/C3.txt 2>&1
```

## Gap

The exact comparison covers `new` and four other renderer families, not every
verb, and it forces no ANSI colour. “Modulo colour” is therefore proved by
running both sampled routes without colour, not by comparing coloured escape
sequences.
