# B1 — new lands inside the tree

## Automated evidence

`new_attaches_and_the_live_pane_has_the_tree_environment` runs `wt new` on a
real pseudoterminal, waits for the private session, asserts exactly one tmux
client is attached, and does not let the command finish until `exit` is sent
through tmux. It also asserts the captured outer terminal contains `Created
repo/work` before the attached session exits.

## Demonstration

Captured outer summary and attached prompt:

```text
Created repo/work
  path    <ROOT>/wt-home/trees/repo/work
  branch  work
  sync    skipped
sh-3.2$
```

Replay: `cargo test --test session_flow new_attaches_and_the_live_pane_has_the_tree_environment -- --exact --nocapture`

## Gap

Gap: tmux's screen-control bytes are asserted behaviorally rather than kept in
the transcript because they vary with terminal implementation; the human
summary and live pane text are retained separately.
