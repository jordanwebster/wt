# B1 — new lands inside the tree

## Automated evidence

`new_attaches_and_the_live_pane_has_the_tree_environment` runs `wt new` on a
real pseudoterminal, waits for the private session, asserts exactly one client,
and proves the `wt` process remains live until `exit` is sent through tmux. The
captured outer terminal must contain the summary before attachment completes.


Regenerate it exactly with:

```sh
env WT_PROOF_CAPTURE=B1 cargo test --quiet --test session_flow new_attaches_and_the_live_pane_has_the_tree_environment -- --exact --nocapture > .handoff/session-ux/captures/B1.txt 2>&1
```

## Gap

capture those bytes and asserts attachment by process liveness and a real client
count rather than treating terminal escape sequences as a stable golden.
