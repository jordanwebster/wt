# B4 — session decision matrix

## Automated evidence

`session_creation_and_attachment_matrix` runs one private server per row and
derives every printed boolean from observed session existence, client count,
and recorder events after asserting it against the decision table.

## Demonstration

Retained capture: `captures/B4.txt`. Verbatim observed matrix:

```text
--- B4 ---
terminal             created=true attached=true agent_started=true
no-terminal          created=true attached=false agent_started=true
activation           created=true attached=false agent_started=true
json                 created=true attached=false agent_started=true
backend-none         created=false attached=false agent_started=false
no-open              created=false attached=false agent_started=false
no-attach            created=true attached=false agent_started=true
attach-setting-false created=true attached=false agent_started=true
```

Regenerate it exactly with:

```sh
env WT_PROOF_CAPTURE=B4 cargo test --quiet --test session_flow session_creation_and_attachment_matrix -- --exact --nocapture > .handoff/session-ux/captures/B4.txt 2>&1
```

## Gap

Only the `terminal` row exercises a live attached client; the negative rows
assert zero clients. `$TMUX` switching is covered at the tmux abstraction
boundary rather than by nesting one private real server inside another.
