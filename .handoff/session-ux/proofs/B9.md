# B9 — remove closes the session

## Automated evidence

`remove_closes_the_private_tmux_session` creates a detached shell session on a
private server, asserts `has-session`, removes the linked tree, then asserts
`has-session` is false. The human transcript snapshot also retains `session
closed` in the removal summary.

## Demonstration

Captured removal transcript:

```text
Removed repo/work
  destroyed  1
  session    closed
```

Replay: `cargo test --test session_flow remove_closes_the_private_tmux_session -- --exact --nocapture`

## Gap

Gap: abrupt tmux-server death during removal is an external failure path and
is not injected by this end-to-end proof.
