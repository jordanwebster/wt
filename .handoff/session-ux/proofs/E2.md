# E2 — the private-session tier is repeatable here

## Automated evidence

The complete `session_flow` integration binary ran three consecutive times.
Each run creates private tmux servers, exercises attachment and pane capture,
and tears its sessions down. Poll loops retain their deadlines but sleep 20 ms
between client processes instead of busy-spinning.

## Demonstration

Retained capture: `captures/E2.txt`. Its complete output is quoted verbatim:

```text
run 1

running 6 tests
......
test result: ok. 6 passed; 0 failed; 0 ignored; 0 measured; 0 filtered out; finished in 14.86s

run 2

running 6 tests
......
test result: ok. 6 passed; 0 failed; 0 ignored; 0 measured; 0 filtered out; finished in 15.31s

run 3

running 6 tests
......
test result: ok. 6 passed; 0 failed; 0 ignored; 0 measured; 0 filtered out; finished in 15.52s
```

Regenerate it exactly with:

```sh
set -o pipefail
{
  for run in 1 2 3; do
    printf 'run %s\n' "$run"
    cargo test --quiet --test session_flow
  done
} > .handoff/session-ux/captures/E2.txt 2>&1
```

## Gap

Three passes disprove immediate local flakiness; they do not prove the absence
of rare races. This tier was not repeated on Linux in this workspace, although
the required workspace matrices passed locally.
