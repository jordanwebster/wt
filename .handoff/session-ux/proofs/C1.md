# C1 — no verb prints a JSON envelope at a terminal

## Automated evidence

`every_successful_verb_uses_intentional_human_text` walks every CLI verb through
the built binary on a pseudoterminal. Each invocation must succeed and its
combined terminal stream must not begin with `{`. `HumanKind::from` remains an
exhaustive match over `cli::Command`, and `human_command_transcripts` separately
snapshots representative complete renderings.

## Gap

The matrix oracle only rejects a leading `{`. The `path`, `exec`, `shell`,
`env`, and script renderer arms intentionally return no wrapper text, so a
regression that printed nothing could still satisfy that narrow assertion.
The capture demonstrates output for those routes, but only the committed
goldens make exact bytes durable, and they do not cover every error route.
